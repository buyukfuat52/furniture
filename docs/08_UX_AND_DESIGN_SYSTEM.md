# UX and Design System

## Product character
Serious, precise and calm B2B manufacturing software. Avoid excessive gradients, neon AI motifs, oversized empty cards and decorative dashboards.

## Information architecture
- Dashboard
- Teklifler / Projeler
- Müşteriler
- Ürün Şablonları
- Malzeme ve Donanım Kataloğu
- Tedarikçi Fiyatları
- Üretim / Paketler
- Raporlar
- Agent Asistanı
- Yönetim / Yetki / Audit

## Quote builder stages
1. Müşteri ve proje
2. Mobilya kalemleri
3. Ölçüler ve ürün konfigürasyonu
4. Malzeme/donanım
5. BOM, kenar ve üretim doğrulaması
6. Nesting ve fire
7. İşçilik ve maliyet
8. Kâr/marj ve ticari koşullar
9. Önizleme ve onay

## Required components
- searchable data table
- money and dimension inputs with explicit units
- product configuration stepper
- BOM tree/table
- four-edge visual editor
- nesting SVG viewer
- cost waterfall/breakdown
- document preview
- revision two-panel diff with filters
- audit timeline
- approval dialog with effect summary
- agent chat with tool/action cards and approval state

## Localization
Use Turkish terminology and `tr-TR` date/number formatting. Keep canonical values independent of display formatting.
