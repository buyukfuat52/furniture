# Web Application Instructions
- Use TypeScript strict mode and server/client boundaries intentionally.
- All API data is validated through generated/typesafe contracts.
- UI language is Turkish; code identifiers remain English.
- Build accessible forms with explicit units and error summaries.
- Never calculate authoritative cost/BOM/nesting in the browser.
- Preserve URL-addressable project/revision state.
- Write component tests for calculation presentation and Playwright tests for primary flows.
- No hardcoded fake totals in production paths.
